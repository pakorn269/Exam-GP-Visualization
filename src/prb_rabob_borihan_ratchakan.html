จุดกับดักที่ชอบออกสอบ

กรุงเทพมหานคร = ราชการส่วนท้องถิ่น ไม่ใช่ส่วนภูมิภาค จึงไม่มี "ผู้ว่าราชการจังหวัด" แต่มี "ผู้ว่าราชการกรุงเทพมหานคร" ซึ่งมาจากการเลือกตั้ง

ราชการส่วนกลาง

กระทรวง / สำนักนายกรัฐมนตรี ม. 17–26
  • จัดตั้ง / ยุบ / เปลี่ยนชื่อ → พ.ร.บ. (ผ่านรัฐสภา)
  • รัฐมนตรีว่าการ = หัวหน้า (ฝ่ายการเมือง, ไม่ใช่ข้าราชการ)
  • ปลัดกระทรวง = หัวหน้าข้าราชการประจำ
  • มีรัฐมนตรีช่วยว่าการ 1 คนหรือมากกว่าก็ได้
กรม ม. 27–35
  • จัดตั้ง / ยุบ / เปลี่ยนชื่อ → พ.ร.ฎ. (ต่างจากกระทรวงที่ใช้ พ.ร.บ.)
  • อธิบดี = หัวหน้ากรม รับผิดชอบต่อรัฐมนตรีว่าการ
  • กรมแบ่งย่อยเป็น สำนัก กอง หรือส่วนราชการเทียบเท่า

ราชการส่วนภูมิภาค

จังหวัด ม. 52–60
  • จัดตั้ง / ยุบ → พ.ร.บ.
  • ผู้ว่าราชการจังหวัด = บังคับบัญชาข้าราชการฝ่ายพลเรือนทุกกรมในจังหวัด
  • คณะกรมการจังหวัด = ทำหน้าที่เป็นที่ปรึกษา ไม่ใช่ผู้มีอำนาจสั่งการ
  • ผู้ว่าฯ ได้รับการแต่งตั้งโดยกระทรวงมหาดไทย ≠ เลือกตั้ง
อำเภอ ม. 61–71
  • จัดตั้ง / ยุบ → พ.ร.ฎ.
  • นายอำเภอ = บังคับบัญชาข้าราชการฝ่ายพลเรือนในอำเภอ
  • แบ่งออกเป็นตำบล หมู่บ้าน (เป็นหน่วยการปกครอง ไม่ใช่ส่วนราชการ)

ทริคลับ 1

ใหญ่ใช้ พ.ร.บ. — รองใช้ พ.ร.ฎ.

กระทรวงและจังหวัดเป็นหน่วยงานสำคัญ ต้องผ่านรัฐสภา = พ.ร.บ.
กรมและอำเภอเป็นหน่วยงานรอง ครม. ตราได้เลย = พ.ร.ฎ.

ทริคลับ 2

กทม. = ท้องถิ่น เพราะ "เลือกตั้ง"

ข้อสอบชอบหลอกว่า กทม. อยู่ส่วนภูมิภาค ตอบได้ทันทีว่า ส่วนท้องถิ่น เพราะผู้ว่าฯ กทม. มาจากการเลือกตั้ง ส่วนผู้ว่าราชการจังหวัดได้รับการแต่งตั้งจากกระทรวงมหาดไทย

ทริคลับ 3

ลำดับหัวหน้า — "นายรัฐ ปลัดอธิ ผู้ว่านาย"

นายก→ รัฐมนตรีว่าการ→ ปลัดกระทรวง→ อธิบดี→ ผู้ว่าฯ→ นายอำเภอ

สีน้ำเงิน = ฝ่ายการเมือง / ข้าราชการชั้นสูงส่วนกลาง | สีเขียว = ส่วนกลาง | สีเหลือง = ส่วนภูมิภาค

ทริคลับ 4

ส่วนท้องถิ่น — จำด้วย "อท อบ กพ"

ทศบาล — เขตเมือง
อบต. — ชนบท
